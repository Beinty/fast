# كتابة سريعة — FastType (HUC)

تطبيق أندرويد يراقب الكتابة بأي تطبيق ويبدّل الاختصارات المحفوظة بالكلمات الكاملة
تلقائياً، قبل الإرسال. يشتغل عن طريق `AccessibilityService` — يعني **مو كيبورد
بديل**، تضل تستخدم كيبوردك المعتاد.

- بدون إنترنت، بدون أي صلاحية شبكة — كل شي محلي بالجهاز
- بدون حد على عدد الاختصارات
- استيراد / تصدير JSON
- يدعم العربي والـ RTL

---

## 1. بناء الـ APK

تحتاج **Android Studio** (أي إصدار حديث) على الحاسبة.

1. افتح Android Studio ← `Open` ← اختر مجلد `FastType`
2. أول مرة راح يسوي Gradle Sync وينزّل الأدوات — انتظر لحد ما يخلص
   - إذا طلب منك ينزّل Gradle wrapper أو SDK، وافق
3. من القائمة: `Build` ← `Build Bundle(s) / APK(s)` ← `Build APK(s)`
4. الملف يطلع هنا:

```
FastType/app/build/outputs/apk/debug/app-debug.apk
```

انقله للموبايل ونصّبه.

> ملاحظة: الـ APK موقّع بمفتاح debug. هذا يكفي للاستخدام الشخصي.
> ما ينفع للنشر على Google Play.

## 2. التفعيل على الموبايل (مهم)

### أ) السماح بالإعدادات المقيّدة

أندرويد ١٣ وأعلى يمنع التطبيقات المنصّبة من خارج المتجر من استخدام إمكانية الوصول.
إذا طلعت لك رسالة **"إعداد مقيّد" / Restricted setting**:

1. الإعدادات ← التطبيقات ← **كتابة سريعة**
2. النقاط الثلاث (⋮) فوق باليمين
3. **السماح بالإعدادات المقيّدة** / Allow restricted settings

### ب) تشغيل الخدمة

1. افتح التطبيق
2. اضغط على الشريط الأحمر فوق ("الخدمة متوقفة")
3. راح ينقلك لـ: الإعدادات ← إمكانية الوصول ← **كتابة سريعة** ← شغّلها
4. ارجع للتطبيق — الشريط يصير أخضر

### ج) على OnePlus / OxygenOS بالذات

افتح الإعدادات ← البطارية ← استهلاك التطبيقات ← **كتابة سريعة** ← خلّيها
**بدون قيود / Don't optimize**، حتى ما يوقّف النظام الخدمة بالخلفية.

## 3. الاستخدام

- اضغط **+ إضافة اختصار**، اكتب الاختصار والكلمة الكاملة
- **ضغطة** على أي سطر = تعديل
- **ضغطة طويلة** = حذف

### وضع "تبديل فوري"

- **مفعّل** (الافتراضي): بمجرد ما تكمل كتابة حروف الاختصار يتبدل فوراً
- **مطفأ**: يتبدل بعد ما تدوس مسافة أو نقطة أو انتر

### الاستيراد الجماعي

جهّز ملف JSON بهذي الصيغة (موجود مثال بـ `sample_shortcuts.json`):

```json
[
  { "trigger": "ببب", "phrase": "بسم الله الرحمن الرحيم", "on": true },
  { "trigger": "سلم", "phrase": "السلام عليكم ورحمة الله وبركاته", "on": true }
]
```

انقله للموبايل واضغط **استيراد** داخل التطبيق. الاستيراد **يدمج** مع الموجود
(الاختصار المكرر يتحدّث بالقيمة الجديدة).

## 4. نقاط تقنية

| الشي | التفصيل |
|---|---|
| `minSdk` | 26 (أندرويد 8) |
| `targetSdk` | 35 |
| حزمة التطبيق | `com.huc.fasttype` |
| التخزين | `SharedPreferences` + JSON |
| الصلاحيات | لا شي عدا `BIND_ACCESSIBILITY_SERVICE` |

### حماية مدمجة

- **حقول كلمات السر مستثناة** — الخدمة تتجاهل أي حقل `isPassword`
- **حدود الكلمة** — الاختصار ما يتبدل إلا إذا كان بداية كلمة، حتى ما يتبدل
  وسط كلمة ثانية
- **حارس التكرار** — يمنع حلقة لا نهائية بعد كل عملية استبدال

### ملفات المشروع

```
app/src/main/java/com/huc/fasttype/
  Store.kt             التخزين + صيغة JSON
  ExpanderService.kt   محرك المراقبة والاستبدال
  MainActivity.kt      الواجهة (مبنية بالكود، بدون XML)
app/src/main/res/
  xml/accessibility_service_config.xml
  values/strings.xml
  drawable/ic_app.xml
```

## 5. التعديل عليه لاحقاً

- **تغيير علامات التبديل** (المسافة/النقطة/الفارزة): دالة `isTriggerChar`
  بملف `ExpanderService.kt`
- **استثناء تطبيقات معينة**: أضف فحص على `event.packageName` بأول
  `onAccessibilityEvent`
- **تغيير الألوان**: الثوابت فوق بملف `MainActivity.kt`
  (`BG` / `CARD` / `ACC`)

## تحذير أمني

التطبيق يأخذ صلاحية **إمكانية الوصول**، يعني تقنياً يشوف محتوى حقول الكتابة.
هذا الكود كله قدامك وتكدر تراجعه — ما بيه أي اتصال شبكة ولا تسجيل ولا إرسال
لأي مكان. لا تنطي هالصلاحية لأي تطبيق ما تعرف مصدره.
